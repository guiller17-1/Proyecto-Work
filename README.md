# Dashboard Truck Visits

Proyecto completo optimizado para Render. Configura CSV_URL con el enlace directo de OneDrive terminado en &download=1.

Build: `pip install -r requirements.txt`

Start: `gunicorn --timeout 120 --workers 1 app:app`

Después de subir todos los archivos, usa en Render: Manual Deploy > Clear build cache & deploy.
